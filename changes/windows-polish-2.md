---
headline: PresentFlow fits smaller Windows laptops, with Windows keyboard labels
audience: operator
version: 0.1.427
date: 2026-09-16
highlights:
  - On smaller Windows laptop screens, the live panel on the right gets a little narrower so your slides keep more room.
  - On very small Windows screens, the search box and the Songs, Bible, Media and Themes buttons show as icons, so the settings button never falls off the edge.
  - If you snap the Windows app to half the screen, the left panel shrinks to fit, and goes back to your chosen width on a bigger window.
  - Windows now shows the right keys in hints and tooltips, for example Ctrl+Z to undo, Ctrl+Enter to save a quick edit, and Shift-click.
  - On Windows, microphone audio is no longer boosted by default when you haven't set a boost. This stops it stacking with Windows' own boost and crackling. Settings › Audio has a tip for setting your Windows mic level. Any boost you've already chosen is kept.
