---
headline: Edit a theme the same way you edit a slide
audience: operator
version: 0.1.438
date: 2026-09-17
highlights:
  - The pencil in the Themes popover (and right-click → Edit…) now opens the full-screen slide editor on that theme.
  - Add more than one slide to a theme, and mark each text box as main text, verse or reference.
  - A new Theme tab holds fonts, background (colour, gradient with angle, image or video, dim, animation), logo (position, size, opacity, auto-colourway), scripture options and the transition.
  - When you save, PresentFlow asks before updating the songs that use the theme. Their words are never changed.
  - The sliders button still opens the old theme screen for now.
