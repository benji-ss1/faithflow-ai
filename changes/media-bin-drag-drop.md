---
headline: Drag files straight into the Media Bin
audience: operator
version: 0.1.427
date: 2026-09-16
highlights:
  - Drag images and videos from Finder or File Explorer onto the Media Bin — each one appears right away with a progress ring and turns into a normal tile when it's done.
  - Drop a PowerPoint or PDF and the import wizard opens with it ready, turning each slide into an image.
  - Dragging files over a closed Media Bin opens it for you. You can drop whole folders too.
  - If an upload fails you get Retry on the tile (and "Retry all" for several); if the internet drops, uploads wait and carry on when you're back online.
  - Audio files and iPhone HEIC photos show a clear message for now instead of silently doing nothing.
  - Dropping a file in the wrong place no longer opens it in another app.
