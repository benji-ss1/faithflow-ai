---
headline: An image you crop or blur in the media editor now stays that way when you use it as a background
audience: operator
version: 0.1.468
date: 2026-09-19
highlights:
  - Crop, zoom, blur the background or place a logo on a colour in the media editor, save it, and every way of using it as a background now uses your edited version — Set as global background, Set as current slide's background, the Bg button, and dragging it onto a slide.
  - Dragging an edited image into the empty part of the slide area adds it as a full-screen slide exactly as you framed it.
  - The first time you use an edited image this way it takes a second or two to prepare; after that it is instant. If you edit it again, the new version is used automatically.
  - If your edit can't be applied for any reason you get a message and the original image is used, so setting a background never fails.
  - The prepared picture appears in your Media Bin with "(framed)" after its name.
